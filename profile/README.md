# C0deGeek-dev

Local-first tooling for running, testing, and orchestrating AI workflows on your own machine.

## LocalStack

The LocalStack projects are a small suite of tools for local AI development:

| Project | Purpose |
| --- | --- |
| [LocalStack](https://github.com/C0deGeek-dev/LocalStack) | Umbrella project and project index |
| [LocalBox](https://github.com/C0deGeek-dev/LocalBox) | Local model runtime and launcher |
| [LocalMind](https://github.com/C0deGeek-dev/LocalMind) | Memory and RAG layer |
| [LocalBench](https://github.com/C0deGeek-dev/LocalBench) | Benchmarking and evaluation |
| [LocalPilot](https://github.com/C0deGeek-dev/LocalPilot) | Local CLI coding agent |
