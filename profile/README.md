# C0deGeek-dev

Local-first tooling for running, testing, and orchestrating AI workflows on your own machine.

## LocalStack

The LocalStack projects form a local-first AI development ecosystem:

| Project | Purpose |
| --- | --- |
| [LocalStack](https://github.com/C0deGeek-dev/LocalStack) | Umbrella project, project index, and GitHub Pages front page |
| [LocalBox](https://github.com/C0deGeek-dev/LocalBox) | PowerShell-driven runtime and launcher for local GGUF models through Claude Code, Codex, or LocalPilot via llama.cpp |
| [LocalMind](https://github.com/C0deGeek-dev/LocalMind) | Host-neutral learning engine that turns opted-in AI development sessions into reviewed project memory, graph-connected knowledge, reusable skills, and local context |
| [LocalBench](https://github.com/C0deGeek-dev/LocalBench) | Benchmarking and evaluation companion that finds stable LocalBox settings, explains tradeoffs, and exports recommended launcher profiles |
| [LocalPilot](https://github.com/C0deGeek-dev/LocalPilot) | Rust-native, provider-neutral coding-agent harness with local-model support and native LocalMind integration |
